# Motor Driver Enclosure

## Overview

This project presents the mechanical design of a compact motor driver enclosure developed using Autodesk Inventor.

The primary objective was to design a robust, manufacturable enclosure that provides reliable protection for electronic components while ensuring easy assembly, maintenance, and future modifications.

---

## Design Objectives

- Compact mechanical design
- Easy assembly
- Manufacturable geometry
- Structural rigidity
- Screw-fastened cover
- Cable management
- Component accessibility

---
